# 04.1 - MongoDB Discovery System

## Overview

Automated MongoDB instance discovery across localhost and network environments. Scans ports, detects Docker containers, and identifies MongoDB servers without manual configuration.

## Quick Start

```bash
mongodb discover                      # Full discovery
mongodb discover --port-range 27000-28000  # Custom ports
mongodb discover --skip-docker        # Skip Docker scan
```

## Discovery Flow

```
User runs "mongodb discover"
    ↓
Load discovery settings
    ↓
Scan localhost (parallel)
    ↓
Scan Docker containers
    ↓
Scan network ranges (parallel)
    ↓
Display results table
```

## Core Components

### NetworkScanner
**File**: `backend/app/core/network_scanner.py`
- Main scanner orchestrator
- Parallel port scanning with threading
- MongoDB connection validation and version detection

### DockerService
**File**: `backend/app/core/docker_service.py`
- Docker container detection and name extraction
- Network inspection and IP mapping

### DiscoverySettings
**File**: `backend/app/core/config/discovery_settings.py`
- Configuration management with defaults
- Port ranges and network definitions

### MongoDBInstance Model
**File**: `backend/app/models/mongodb_instance.py`
- Data structure for discovered instances
- Properties: host, port, version, auth status, Docker info

## Discovery Methods

### Localhost Scan
- Default ports: 27017-27019
- Fast timeout: 2 seconds
- Parallel connection attempts

### Docker Scan
- Lists running containers
- Filters by MongoDB image
- Maps container networks to IPs
- Extracts container names

### Network Scan
- Auto-detect Docker networks
- CIDR notation support (e.g., `172.19.0.0/24`)
- Configurable port ranges
- Parallel scanning for performance

## Configuration

**File**: `backend/app/core/config/discovery_config.json`

Default settings:
- Localhost ports: 27017-27019
- Network scan: enabled
- Docker scan: enabled
- Timeout: 2 seconds
- Port range: 27000-27100

## Performance

- Localhost: ~1 second
- Docker: ~2 seconds
- Network: ~5-10 seconds
- Total: ~10-15 seconds
