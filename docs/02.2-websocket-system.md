# 02.2 - WebSocket System

## Overview

Real-time bidirectional communication between frontend terminal and backend command executor using native WebSocket protocol.

## WebSocket Endpoint

**URL**: `ws://localhost:9000/ws/terminal?token=<jwt_token>`

**Authentication**: JWT token passed as query parameter

## Message Flow

### Client → Server (Command Execution)
```
User types command in terminal
    ↓
Frontend sends: {"type": "execute", "command": "connect list"}
    ↓
Backend receives message
    ↓
Parse command with CLIParser
    ↓
Execute command
    ↓
Stream output back to client
```

### Server → Client (Output Streaming)
```
Command execution starts
    ↓
For each output line:
    Send: {"type": "output", "line": "Connection: prod-db"}
    ↓
Command completes:
    Send: {"type": "complete", "status": "success"}
```

## Message Types

### 1. Execute Request (Client → Server)
```json
{
  "type": "execute",
  "command": "connect list"
}
```

### 2. Output Message (Server → Client)
```json
{
  "type": "output",
  "line": "Available connections:",
  "timestamp": "2024-01-20T19:00:00Z"
}
```

### 3. Complete Message (Server → Client)
```json
{
  "type": "complete",
  "status": "success",
  "exit_code": 0
}
```

### 4. Error Message (Server → Client)
```json
{
  "type": "error",
  "error": "Connection not found",
  "timestamp": "2024-01-20T19:00:00Z"
}
```

## Backend Implementation

**File**: `backend/app/websocket/terminal.py`

### Connection Handling
```python
@app.websocket("/ws/terminal")
async def websocket_endpoint(websocket: WebSocket, token: str):
    # Verify JWT token
    username = await verify_websocket_token(token)
    
    # Accept connection
    await websocket.accept()
    
    try:
        while True:
            # Receive command
            data = await websocket.receive_json()
            
            # Parse and execute
            command = data.get("command")
            await execute_command(websocket, command)
    
    except WebSocketDisconnect:
        # Cleanup on disconnect
```

### Output Streaming
```python
async def send_output(websocket: WebSocket, line: str):
    await websocket.send_json({
        "type": "output",
        "line": line,
        "timestamp": datetime.now(UTC).isoformat()
    })
```

## Frontend Implementation

**File**: `frontend/app/composables/useWebSocket.ts`

### Connection Management (Singleton Service)
```typescript
class WebSocketService {
  private socket: WebSocket | null = null
  private messageHandlers: Array<(msg: WebSocketMessage) => void> = []
  
  connect(token: string, wsUrl: string) {
    const url = `${wsUrl}/ws/terminal?token=${token}`
    this.socket = new WebSocket(url)
    
    this.socket.onmessage = (event) => {
      const message = JSON.parse(event.data)
      this.messageHandlers.forEach(handler => handler(message))
    }
  }
  
  sendCommand(command: string): boolean {
    this.socket.send(JSON.stringify({
      type: 'execute',
      command
    }))
    return true
  }
}
```

## Connection Lifecycle

### 1. Establish Connection
```
User logs in → Receives JWT token
    ↓
Frontend calls wsService.connect(token, wsUrl)
    ↓
WebSocket connects with token in query params
    ↓
Backend verifies token
    ↓
Connection accepted
```

### 2. Send Command
```
User types "help" → Presses Enter
    ↓
CommandInput calls executeCommand("help")
    ↓
TerminalService calls wsService.sendCommand("help")
    ↓
WebSocket sends {"type": "execute", "command": "help"}
```

### 3. Receive Output
```
Backend processes command
    ↓
For each output line:
    Backend sends {"type": "output", "line": "..."}
    ↓
Frontend WebSocket.onmessage receives message
    ↓
Calls all registered message handlers
    ↓
TerminalService updates commandHistory
    ↓
TerminalOutput re-renders with new output
```

### 4. Disconnect
```
User logs out OR closes browser
    ↓
Frontend calls wsService.disconnect()
    ↓
WebSocket.close() called
    ↓
Backend receives WebSocketDisconnect
    ↓
Cleanup resources
```

## Error Handling

- **Invalid Token**: Connection rejected with 403 Forbidden
- **Connection Lost**: Frontend auto-reconnect with exponential backoff
- **Command Error**: Error message sent via WebSocket (type: "error")
- **Max Reconnect Attempts**: 5 attempts, then stop
